# Changelog

## 0.1.1

- Added a package screenshot and direct pub.dev documentation links.
- Reworked the package overview around developer value, global reuse, and
  customization across sports and visual strategy use cases.
- Clarified host control over tools, playing surfaces, layouts, icons,
  configuration, persistence, and export workflows.

## 0.1.0

- Initial public release.
- Added host-defined layouts and configurable colors and stroke widths.
- Added 86 canonical drawing, line, shape, text, and marker tools with bundled
  SVG artwork and custom icon fonts.
- Added host-selected tool sets, custom toolbar icons, and marker renderers for
  hidden tools in restored documents.
- Added multiline text creation and editing.
- Added move, independent scale, and independent rotation controls for strokes,
  text, and markers.
- Added responsive toolbars, touch targets, semantic labels, desktop cursors,
  and support for compact and short viewports.
- Added undo, redo, confirmed canvas clearing, versioned JSON import/export,
  and PNG generation.
